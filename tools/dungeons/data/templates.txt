# templates.txt — room templates for SuperForge Dungeons' level generator.
#
# THIS FILE IS SOURCE DATA. The reference model (tools/dungeons/levelgen.py)
# reads it; the future asset generator packs it into a ROM blob; the tests use
# the model as their oracle. Spec: docs/dungeons/03_level_generation.md.
#
# A cell is 16x16 metatiles (16x16 px each = 256x256 px). Only the 14x14
# INTERIOR is authored here; the generator stamps the border itself: solid
# wall, with a 2-metatile DOOR GAP at the middle of each side the cell is
# connected on (N/S: columns 7-8, W/E: rows 7-8 of the full 16x16 cell).
#
# Header:  @name  type=<start|normal|treasure|boss>  doors=<subset of NESW>
#          weight=<1..255>  [flip=yes]
#   doors  = the sides this template CAN open (the validator proves each one
#            reaches the room's walkable interior). The generator only places
#            a template where needed_doors ⊆ doors.
#   flip   = may be mirrored left-right at stamp time (E and W swap).
#
# Legend (one char = one metatile):
#   .  floor            #  wall (blocks walk + shots)   o  pillar (same as #, own art)
#   ~  chasm (blocks walk, NOT shots)                    :  rubble (floor, decor)
#   s  player start     x  exit stairs                   B  boss anchor
#   e  enemy pack       c  chest                         t  brazier (floor, decor, light)
#
# Every marker sits on walkable floor; the generator replaces it with floor in
# the map and records it in the spawn table.
